# 카카오톡 예약 메시지 일괄 등록 (kakao-schedule-runner)

> 카카오톡 데스크톱의 **메시지 예약** 기능으로 여러 날짜의 메시지를 한 번에 걸어둔다. 서버측 예약이라 PC를 꺼도 발송된다. macOS와 Windows 데스크톱 모두 지원한다.

## 왜 만들었나

단톡방에 매일 같은 시각에 알림(예: 일일 미션 체크)을 보내려면 한 달치 예약을 하나씩 손으로 걸어야 합니다. 이 스킬은 Claude가 카카오톡 데스크톱 화면을 조작해 그 작업을 대신하고, **등록 전에 기존 예약을 먼저 점검해** 중복·누락·날짜 오류를 막습니다.

## 전체 흐름

> 범위·문구 확정 → 스크립트로 날짜표 생성 → **기존 예약 전수 감사** → 차집합만 등록 → 재감사

| 단계 | 하는 일 |
|---|---|
| 0. 확정 | 대상 채팅방, 발송 기간, 발송 시각, 문구 규칙을 정합니다. 문구는 추측하지 않고 기존 예약이나 채팅방 기록에서 그대로 복사합니다. |
| 1. 날짜표 생성 | 날짜 계산은 스크립트가 합니다. 발송일 D에 D−1 날짜를 적는 규칙은 손으로 세면 반드시 어긋나기 때문입니다. 이 표가 이후 모든 검증의 정답지입니다. |
| 2. 기존 예약 감사 | 예약 목록을 처음부터 끝까지 읽고 중복, 누락, 날짜 어긋남, 시각 어긋남을 찾습니다. 방별 건수 합계가 화면의 "대기 N개"와 맞는지 검산합니다. 결과는 사용자에게 먼저 보고하고, 삭제나 보충은 확인을 받은 뒤 실행합니다. |
| 3. 등록 | 정답지에 **아직 없는 날짜만** 넣습니다. 이미 있는 예약은 건드리지 않습니다. |
| 4. 재감사 | 등록 후 감사를 다시 돌려 정답지와 1:1로 대조하고, 최종 건수가 "감사 시점 건수 + 등록 건수"와 일치하는지 확인합니다. |

## 이 스킬이 이렇게 생긴 이유

실제로 겪은 두 가지 사고를 막도록 절차 전체가 짜여 있습니다.

1. **채팅 입력창 경로는 오발송을 낸다.**
   채팅 입력창에 문구를 타이핑하고 `+ → 메시지 예약`으로 들어가면 예약을 건 뒤에도 초안이 입력창에 그대로 남습니다. 이후 아무 클릭에서나 실제 전송이 터집니다. 18명 단톡방에 자정 오발송이 이렇게 났습니다. 그래서 이 스킬은 채팅 입력창을 전혀 거치지 않는 **브리핑 보드 경로만** 씁니다.
2. **기존 예약은 이미 틀어져 있을 수 있다.**
   사람이 손으로 넣어 둔 예약에서 중복 2건과 누락 1건이 발견됐습니다. 확인 없이 새로 넣으면 중복 위에 중복을 얹게 됩니다. 그래서 **감사가 등록보다 먼저**입니다.

## 실제 운영에서 반영한 사항

| 발견한 문제 | 반영한 절차 |
|---|---|
| 대기 예약이 100건에서 101번째 등록이 거부됐습니다. 계정당 최대 100건이며 개인 예약도 합산됩니다. | 시작 전에 남은 슬롯(100 − 대기 건수)을 계산하고, 넣으려는 건수가 더 많으면 미리 알립니다. 방이 둘이면 날짜순으로 번갈아 넣어 한도에 걸려도 양쪽이 같은 지점까지 차 있게 합니다. |
| 건마다 화면을 캡처해 검증하면 대량 작업이 몇 배 느려졌습니다. | 값 4개(본문·방·날짜·시각)를 채우면 바로 예약을 누르고, 검증은 예약 직후 캡처 1장으로 합니다. 서버 예약이라 발송 전에는 지우면 그만입니다. |
| 이름이 비슷한 채팅방을 잘못 고를 위험이 있었습니다. | 방 선택 시 인원수와 마지막 메시지로 구별합니다. |
| 팝업 렌더가 느려서 클릭이 빗나가거나 멈추는 경우가 있었습니다. | 대기 시간, 스크롤 위치, 월 이동 클릭 횟수를 절차에 넣고, 새 달의 첫 건은 달력을 확인한 뒤 진행합니다. |
| 실수로 전송된 경우 5분 안에 회수해야 합니다. | 사고 대응 절차를 정했습니다. 확인을 기다리지 않고 회수부터 하고, 흔적과 알림이 남는다는 사실을 사용자에게 그대로 알립니다. |

## 안전장치 요약

- 채팅 입력창 경로를 쓰지 않습니다. (오발송 방지)
- 등록 전에 기존 예약을 전수 감사합니다. (중복·누락 방지)
- 날짜는 손으로 계산하지 않고 스크립트로 생성합니다.
- 삭제와 보충은 사용자 확인 후 실행합니다.
- 등록 후 재감사로 정답지와 1:1 대조합니다.
- 작업 후 채팅 입력창에 남은 초안이 없는지 점검합니다.

## 구성 요소

- 스크립트: 날짜표 생성 (`--offset`, `--template`, `--weekdays-only` 옵션)
- 참고 문서: 화면 랜드마크·좌표 기록 (macOS / Windows), 채팅방 정보

상세 절차와 스크립트는 비공개 저장소에서 관리합니다.
