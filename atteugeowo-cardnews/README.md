# 아뜨거워 카드뉴스 (atteugeowo-cardnews)

> 네이버 뉴스 랭킹에서 오늘 화제 뉴스를 골라 → 〈아뜨거워〉 톤으로 문구를 쓰고 → 캔바 카드로 만든다. 평일 오전 9시 인스타그램 매거진 발행용. **결정론 단계(수집·군집·랭킹·레이아웃 검증)는 스크립트가, 판단 단계(선정·작성·카드 조작)는 AI가 맡는다.**

## 왜 만들었나

인스타그램 뉴스 매거진 〈아뜨거워〉는 평일 오전 9시에 카드뉴스 9장을 발행합니다. 매일 아침 뉴스를 훑고, 이슈를 고르고, 문구를 쓰고, 카드를 한 장씩 만드는 데 드는 시간을 없애는 것이 목적입니다. 이 스킬 하나로 **수집 → 선정 → 문구 → 캔바 카드 → 캡션 → 검수 → 이력 기록**까지 이어집니다.

## 전체 흐름

| 단계 | 하는 일 | 담당 |
|---|---|---|
| 1 | 수집 윈도우 산정 (전날 오전 ~ 당일 오전, 월요일은 72시간) | AI 판단 |
| 2 | 후보 수집: 네이버 "많이 본 뉴스" 랭킹 + 부처 보도자료·연합뉴스 분야별·과학 매체 피드, 같은 사건끼리 군집화 후 보도량 랭킹 | 스크립트 |
| 3 | 화제성과 카테고리 다양성을 함께 보고 7~10개 선정 | AI |
| 4 | 원문을 읽고 제목·본문 3문장 작성, 자수·강조 비중 검증 후 편집 명령 생성 | AI + 스크립트 |
| 5 | 캔바 카드 생성, 커밋 전 글자 단위 대조 | Canva MCP + 스크립트 |
| 6 | 인스타 캡션과 해시태그 작성 | AI |
| 7 | 레이아웃 실측(줄 수, 우측끝 편차) 후 사람이 검수 | 스크립트 + 사람 |
| 8 | 발행 이력 기록, 다음 실행에서 같은 이슈 재선정 방지 | 스크립트 |

## 설계 원칙

**1. 두 가지 모드**
- "후보 줘"라고 하면 3단계까지만 하고 멈춰서 후보 15~20건을 보여 줍니다.
- "카드뉴스 만들어줘"라고 하면 후보 확인을 받은 뒤 4~8단계로 진행합니다.
- 후보 단계에서는 원문을 읽지 않고 제목과 요약만 씁니다. 사용자가 고른 기사만 원문을 읽어 토큰과 시간을 아낍니다.

**2. 판단은 AI, 검증은 스크립트**
- 제목 15자 초과, 본문 자수, 강조 비중, 문장 수, 편집 위치의 유일성은 스크립트가 잡습니다. 오류가 1건이라도 있으면 편집 명령 자체를 만들지 않습니다.
- 카드 문구는 JSON 한 파일에 모으고, 스크립트가 캔바 편집 명령을 통째로 만듭니다. AI가 손으로 다시 옮겨 적지 않습니다.
- 캔바에 반영하기 전에 글자 단위로 원문과 대조합니다.
- 줄 수와 넘침은 눈대중이 아니라 렌더된 PNG 픽셀로 잽니다.

**3. 이슈 선정 기준**
- 정치·경제는 반드시 다룹니다. 다만 프레임을 바꿔서 "누가 이겼나"가 아니라 "제도가 어떻게 바뀌고 내 삶에 뭐가 달라지나"로 씁니다.
- 6개 유형에서 최소 4장을 채웁니다: 제도·정책 변화 / 생활비·지출 / 브랜드·인물의 반전 / 기관의 공식 판단 / 과학·기술 성과 / 재미·화제성
- 재미·화제성 카드는 매일 1~2장 고정으로 넣습니다. 피해자나 논쟁 당사자가 없는 재미만 씁니다.
- 카드 1번은 그날 화제성이 가장 큰 이슈이고, 뒤로 갈수록 정보성·생활형으로 배치합니다.
- 이미 발행한 이슈는 자동으로 걸러냅니다.

**4. "왜 오늘 기사화됐나"를 먼저 판별**
랭킹에 오른 기사는 오늘 터진 사건이 아니라 오래된 사건에 새 전개(보상안, 법원 판단, 정부 대책)가 붙은 경우가 많습니다. 제목과 첫 문장은 새 전개에 맞추고, 원래 사건은 시점을 밝혀 배경으로만 씁니다.

**5. 쉬운 말로 쓴다**
후보 목록도 카드 문구도 전문용어 압축형이 아니라 일반 독자가 바로 이해하는 문장으로 씁니다.

## 실제 운영에서 개선한 사례

이 스킬은 한 번에 완성되지 않았고, 매번 겪은 문제를 절차에 반영하며 다듬었습니다.

| 문제 | 개선 |
|---|---|
| 한글을 `\uXXXX`로 손으로 조합해 카드 문구에 오타가 반복됐습니다(하루 최대 10장 중 5장). "조심하라"는 경고를 4번 추가했는데도 빈도가 줄지 않았습니다. | 규칙을 "하지 마라"에서 "이렇게 해라"로 바꿨습니다. 편집 명령을 스크립트가 만들고 AI는 그대로 붙여넣기만 합니다. 붙여넣기 전 검증 스크립트가 어긋난 명령을 거부합니다. |
| 랭킹 소스만 쓰면 정치 공방·연예·사건사고가 상위를 채우고 정책·과학 기사가 거의 안 올라왔습니다. 실측에서 그날 발행 9건 중 7건이 수집 후보 안에 없었습니다. | 보도자료·연합뉴스 분야별·과학 매체 피드를 두 번째 수집기로 추가해 두 소스를 항상 같이 돌립니다. |
| 오래된 사건을 방금 터진 것처럼 써서 독자가 오해할 수 있었습니다. | 원문에서 "원래 사건 발생일"과 "오늘의 새 전개"를 구분한 뒤 제목을 새 전개에 맞추는 절차를 추가했습니다. |
| 이미 발행한 기사가 후보에 다시 올라온 적이 있었습니다. | 발행 이력을 기록하고, 두 수집 소스 모두에서 자동으로 제외합니다. |
| 캔바 카드 10장을 한 대화에서 만들면 문맥이 계속 커져 회당 토큰이 크게 늘었습니다. | 카드 제작 단계를 서브에이전트에 넘겨 메인 대화에는 요약 결과만 돌아오게 했습니다. |

## 결과물

- 카드 이미지 9장 (1080×1350 PNG)
- 인스타그램 캡션과 해시태그 (`본문.txt`)
- 평일 아침 자동 실행으로 만들어 두는 후보 목록
- 발행 이력 (`published.json`)

## 자동 실행

Windows 작업 스케줄러가 평일 오전 8시에 후보 수집과 선정(3단계까지)을 자동으로 돌립니다. 공휴일은 스크립트가 구글 한국 공휴일 캘린더로 판정해 건너뜁니다. 최종 선정과 카드 제작은 사람이 후보를 확인한 뒤 이어서 진행합니다. 실측 소요 시간은 약 3분 30초입니다.

## 설정값

| 항목 | 값 |
|---|---|
| 발행 요일 | 평일(월~금), 공휴일 제외 |
| 발행 시각 | 오전 9시 목표 |
| 카드 수 | 9장 기본 (7~10장) |
| 제목 | 2줄, 각 8~15자 |
| 본문 | 3문장, 140~180자, 6줄 목표 |

## 구성 요소

- 스크립트 8개: 랭킹 수집, 피드 수집, 편집 명령 생성, 붙여넣기 전 검증, 글자 대조, 레이아웃 실측, 발행일 판정, 자동 실행
- 참고 문서 2개: 선정·캡션 기준, 문체·레이아웃 가이드

상세 절차와 스크립트는 비공개 저장소에서 관리합니다.
